# Tehnički zadatak – Mid Backend Developer

## Opis zadatka

Potrebno je unutar postojeće strukture projekta implementirati sustav koji bi upravljao
korisnicima, košaricama i proizvodima. Aplikacija treba koristiti DummyJSON API kao
vanjski servis za dohvaćanje proizvoda te omogućuje korisnicima dodavanje artikala
u košaricu.

Kostur rješenja je u trenutnom git repozitoriju.

💡Ako želiš pokazati i svoje znanje FrontEnd-a i tako zaraditi bonus bodove, u
AbySalto najčešće koristimo ReactJS i Angular.

⏳ Procjena vremena rješavanja: 4 sata

Funkcionalnosti aplikacije
👤 Korisnici
    Registracija korisnika
    Prijava korisnika
    Dohvat informacija o trenutno prijavljenom korisniku
🛍️ Proizvodi
    🔹 Dohvat svih proizvoda
    🔹 Dohvat pojedinačnog proizvoda
    🔹 Dodavanje proizvoda u favorite
🛒 Košarica
    🛠️ Dodavanje proizvoda u korisnikovu košaricu
    🛠️ Uklanjanje proizvoda iz košarice
    🛠️ Dohvat trenutne korisnikove košarice

🌟 Dodatni zadaci (Bonus)
🎯 Struktura projekta – Želimo vidjeti kako organiziraš kod i koristiš principe Clean
Arhitekture
🎯 Paginacija i sortiranje: Omogućiti dohvat proizvoda uz podršku za paginaciju i
sortiranje
🎯 Caching podataka: Implementirati caching kako bi se smanjio broj poziva prema
DummyJSON API-ju i poboljšala efikasnost aplikacije

🛠️ Tehnički zahtjevi
✅ Baza podataka – Podaci se trebaju spremati i dohvaćati iz baze podataka
🚀 Kako predati zadatak
Postavi rješenje na online repozitorij i pošalji nam link ili pošaljite git bundle.
Očekujemo commitove tijekom razvoja, a ne samo finalno rješenje. Dodaj README
file s uputama za pokretanje aplikacije.
